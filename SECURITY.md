# Security policy

Please do not open a public issue for a vulnerability, such as a memory-safety bug that
can be triggered remotely.

Report it privately through GitHub instead: open the repository's **Security** tab and
choose **Report a vulnerability**. For giong that is
<https://github.com/giong-run/Giong/security/advisories/new>.

Include the kernel version (`uname -r`), the giong version or commit, and the smallest
program that shows the problem. The fix
will be released before the report is made public.

## Supported versions

Only the latest release receives security fixes while giong is below 1.0.
